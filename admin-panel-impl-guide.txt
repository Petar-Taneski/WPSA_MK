1  OVERVIEW
-----------
Goal: Replace the dummy `src/pages/Admin.tsx` with a fully-functional admin
dashboard that lets privileged users — 
 • list news articles and events with infinite scroll;
 • create new records;
 • edit existing records; and
 • delete records.

Tech decisions
• Uses the existing Firestore backend (`news`, `events` collections).
• CRUD operations live in `src/services/api.ts`.
• Data fetching → SWR (`useSWRInfinite`) for list views, SWR (`useSWR`) for
  single-item fetch after navigation to edit form.
• UI split in two tabs:  News  |  Events.
• Forms built with React-Hook-Form + Zod (already in deps via react-hook-form,
  add `zod` if missing).
• Image upload handled through Firebase Storage.
• Route protected by current `ProtectedRoute` + simple "admin" role check.

4.2  NEWS CRUD
──────────────
```ts
export type NewsArticleInput = Omit<NewsArticle, "id" | "publishDate"> & {
  publishDate?: Date;           // allow optional in input
};

export const createNewsArticle = async (
  data: NewsArticleInput,
  uid: string
) => {
  const ref = await addDoc(collection(db, "news"), {
    ...data,
    publishDate : data.publishDate ?? serverTimestamp(),
    createdAt   : serverTimestamp(),
    updatedAt   : serverTimestamp(),
    createdBy   : uid,
    updatedBy   : uid,
  });
  return ref.id;
};

export const updateNewsArticle = async (
  id: string,
  data: Partial<NewsArticleInput>,
  uid: string
) => {
  await updateDoc(doc(db, "news", id), {
    ...data,
    updatedAt : serverTimestamp(),
    updatedBy : uid,
  });
};

export const deleteNewsArticle = async (id: string) =>
  deleteDoc(doc(db, "news", id));
```

4.4  INFINITE FETCH
Extend existing `fetchNewsArticlesFromFirebase`  
and `fetchEventsFromFirebase` to optionally accept a *DocumentSnapshot* for
pagination:

```ts
export const fetchNewsChunk = async (
  lang: string,
  tag: string | null,
  pageSize = 15,
  lastDoc?: QueryDocumentSnapshot<DocumentData>
) => {
  let q = query(
    collection(db, "news"),
    where("lang", "==", lang === "en" ? "english" : "macedonian"),
    orderBy("publishDate", "desc"),
    limit(pageSize)
  );
  if (tag)      q = query(q, where("tags", "array-contains", tag));
  if (lastDoc)  q = query(q, startAfter(lastDoc));

  const snap = await getDocs(q);
  const items = snap.docs.map(d => ({
    id: d.id,
    ...d.data(),
    publishDate: formatDate(d.data().publishDate.toDate(), lang),
    _doc: d                                     // keep ref for pagination
  })) as (NewsArticle & { _doc: DocumentSnapshot })[];

  return { items, lastDoc: snap.docs.at(-1) };
};
```

Do the same for events.


5  SWR + INFINITE SCROLL HOOKS
------------------------------
Create `src/hooks/useInfiniteNews.ts` and `useInfiniteEvents.ts`.

```ts
import useSWRInfinite from "swr/infinite";
import { fetchNewsChunk } from "@/services/api";

const PAGE_SIZE = 15;

export const useInfiniteNews = (lang: string, tag: string | null) => {
  const getKey = (pageIndex: number, previous: any) => {
    if (previous && !previous.items.length) return null; // reached end
    if (pageIndex === 0) return ["news", lang, tag, null];
    return ["news", lang, tag, previous.lastDoc];
  };

  const fetcher = (key: any[]) => {
    const [, l, t, last] = key as [string, string, string | null, any];
    return fetchNewsChunk(l, t, PAGE_SIZE, last);
  };

  const { data, error, size, setSize, mutate, isLoading } = useSWRInfinite(
    getKey,
    fetcher,
    { revalidateFirstPage: false }
  );

  const flat = data?.map(d => d.items).flat() ?? [];
  const isEnd = data?.[data.length - 1]?.items.length < PAGE_SIZE;

  return { flat, error, size, setSize, isEnd, mutate, isLoading };
};
```

Use IntersectionObserver on the last list item to call `setSize(size + 1)`.

7  CREATE / EDIT / DELETE FLOWS
-------------------------------
1. User clicks "Create".  
2. `FormModal` opens with empty default values.  
3. On submit → call `createXxx()`.  
4. On success: close modal, call `mutate()` on list SWR.

Editing is identical except form is pre-filled using `useSWR` to fetch single
doc on modal open.

Deleting:
```
await deleteNewsArticle(id);
mutate(prev => prev?.filter(i => i.id !== id));
```

Toast notifications are already configured (`react-toastify`).


8  AUTHENTICATION & AUTHORISATION
---------------------------------
`ProtectedRoute` currently checks for any logged-in user.  We need an admin
check:

```ts
const isAdmin = async (user: User) => {
  const token = await user.getIdTokenResult();
  return !!token.claims.admin;
};
...
if (!user || !(await isAdmin(user))) return <Navigate to="/login" replace/>;
```

Add helper `useIsAdmin()` or extend `AuthContext`.

Alternatively store a list of admin-UIDs in `/config/admins.json` or in
Firebase Remote Config.


9  VALIDATION, RICH-TEXT & UPLOADS
----------------------------------
• Install zod: `npm i zod @hookform/resolvers`.  
• Use `react-quill` or "TipTap" for rich text in `content` field.  
• Summary can stay a textarea with max length 300.  
• Validate required fields: `title`, `summary`, `content`, `lang`.
• Use Date Picker (`@headlessui/react` or `react-date-picker`) for eventDate.

Example Zod schema:
```ts
const NewsSchema = z.object({
  title: z.string().min(5),
  summary: z.string().min(10).max(300),
  content: z.string().min(20),
  lang: z.enum(["english", "macedonian"]),
});
```
